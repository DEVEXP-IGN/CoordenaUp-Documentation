Bem-vindo

SpendMate é um sistema robusto e escalável para gestão financeira corporativa. Esta documentação técnica fornece informações detalhadas sobre a arquitetura, modelos de dados e funcionalidades do sistema.

Documentação

Acesse a documentação completa do sistema para detalhes sobre:

  • Todas as models de dados
  • Associações e relacionamentos
  • Validações e callbacks
  • Scopes e métodos públicos
  • Controllers e funcionalidades
  • Services e jobs

Acesse também a documentação de Usuários, com páginas específicas para visualização e hierarquia de funções e permissões.

Deploy no GitHub Pages

Este repositório está pronto para ser publicado no GitHub Pages.

Passos para publicar:

  1. Acesse Settings > Pages no seu repositório
  2. Selecione Deploy from a branch
  3. Escolha a branch principal (main/master)
  4. Selecione a pasta / (raiz)
  5. Clique em Save

Seu site será publicado em https://seu-usuario.github.io/coordenaup-documentation
