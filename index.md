## 🔗 Deploy no GitHub Pages

Este site está pronto para ser publicado no GitHub Pages usando a configuração **Deploy from a branch**:

1. Abra **Settings > Pages** no seu repositório
2. Selecione **Deploy from a branch**
3. Escolha a branch principal
4. Selecione a pasta raiz `/`
5. Salve as configurações

Seu site será publicado automaticamente em `https://seu-usuario.github.io/repositorio/`
