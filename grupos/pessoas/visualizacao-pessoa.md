# Pessoas

## Visualização de Pessoa

![Figura 81 - Visualização de Pessoa]({{ '/assets/media/images/pessoas/pessoas_show.png' | relative_url }})

<p class="caption">Figura 81 - Visualização de Pessoa</p>

Apresenta todos os dados cadastrados de forma organizada para conferência.

- **Exibição de Dados:** Exibe Nome, CPF, Tipo, Endereço, Contatos e Dados Bancários em modo de leitura.

- **Ações de Visualização:**
  - **Botão Editar:** Atalho para modificar as informações da pessoa.
  - **Botão Voltar:** Retorna para a lista de pessoas.
