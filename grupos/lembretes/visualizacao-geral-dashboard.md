# Lembretes

## Visualização Geral (Dashboard)

![Figura 114 - Visualização Geral (Dashboard)]({{ '/assets/media/images/lembretes/lembretes_index.png' | relative_url }})

<p class="caption">Figura 114 - Visualização Geral (Dashboard)</p>

Ao acessar o sistema, o usuário é imediatamente apresentado à lista de lembretes ativos. Diferente de uma agenda comum, o foco aqui é a proximidade do prazo.

### Origem dos Dados

Os lembretes exibidos são automaticamente extraídos dos campos "Data de Lembrete" e "Descrição do Lembrete" preenchidos no cadastro de cada Projeto.

### Colunas da Tabela

- **Prioridade (Cor):** Identificação visual imediata do nível de urgência.
- **Data:** A data específica configurada para o alerta.
- **Projeto:** O nome do projeto ao qual o lembrete se refere.
- **Descrição:** O texto explicativo sobre o que deve ser feito (ex: "Enviar relatório parcial", "Assinar aditivo de prazo").

Esta visualização centralizada permite que o gestor mantenha controle sobre todos os compromissos críticos em um único ponto de acesso.
