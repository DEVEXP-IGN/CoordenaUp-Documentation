# Usuários

## Listagem de Usuários

![Figura 82 - Listagem de Usuários]({{ '/assets/media/images/usuarios/usuarios_index.png' | relative_url }})

<p class="caption">Figura 82 - Listagem de Usuários</p>

A tela de listagem permite gerenciar quem tem autorização para acessar o sistema e verificar o status de seus perfis.

- **Filtros de Busca:**
  - **Pesquisar:** Busca por nome ou e-mail do usuário.
  - **Função:** Filtra os usuários por seu nível de acesso (ex: Administrador, Gestor).
  - **Botão Filtrar:** Aplica os filtros à tabela.

- **Colunas da Tabela:**
  - **Nome:** Identificação do usuário.
  - **E-mail:** Login de acesso ao sistema.
  - **Função:** Perfil de permissão atribuído.

- **Ícones de Ação:**
  - **Olho (Azul):** Visualiza os detalhes e permissões do usuário.
  - **Lápis (Amarelo):** Edita dados cadastrais e altera a função de acesso.
  - **Lixeira (Vermelho):** Remove o acesso do usuário ao sistema.

- **Navegação:**
  - **Botão Adicionar (+):** Abre o formulário para criar um novo acesso.
  - **Botão Voltar:** Retorna ao menu administrativo.
