# Receitas

## Fluxo de Recebimento

O fluxo de recebimento descreve como uma receita evolui desde o planejamento no projeto até a confirmação do crédito na conta financeira.

1. **Geração:** Ao definir as parcelas no projeto, o sistema cria automaticamente as receitas com status `Prevista`.
2. **Faturamento:** Quando o setor administrativo emite a cobrança, o status é alterado para `Faturada`.
3. **Liquidação:** Ao confirmar o crédito em conta, o usuário altera a receita para `Recebida` e informa a data do crédito. Nesse momento, o saldo da Conta Financeira vinculada é atualizado positivamente.
