# Contas Financeiras

O módulo de Contas Financeiras no CoordenaUP é utilizado para cadastrar e gerenciar as contas bancárias ou fundos de reserva operados pela Unidade de Pesquisa (UP). Este cadastro serve como a base para o registro de todas as movimentações financeiras, permitindo a visualização do saldo bancário real e os saldos dos projetos.
