# Usuários

## Cadastro e Edição de Usuário

![Figura 83 - Cadastro e Edição de Usuário]({{ '/assets/media/images/usuarios/usuarios_edit.png' | relative_url }})

<p class="caption">Figura 83 - Cadastro e Edição de Usuário</p>

Esta interface realiza a ponte entre o cadastro de "Pessoa" e a conta de "Usuário".

- **Campos do Formulário:**
  - **\*Pessoa:** Seleção da pessoa (previamente cadastrada no módulo de Pessoas) que receberá o acesso.
  - **\*E-mail:** Endereço de e-mail que servirá como login único.
  - **\*Senha:** Definição da senha de acesso (no modo de edição, este campo permite a atualização da credencial).
  - **\*Função:** Define o papel do usuário no sistema e, consequentemente, suas permissões.

- **Ações:**
  - **Botão Cancelar:** Aborta a operação.
  - **Botão Salvar:** Confirma a criação ou alteração do usuário.
