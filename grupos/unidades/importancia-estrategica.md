# Unidades de Pesquisa (UP)

## Importância Estratégica

A Unidade de Pesquisa funciona como o filtro mestre do sistema. Por ser uma configuração inicial e estrutural, ela determina o escopo dos dados operacionais do CoordenaUP.

Todos os registros financeiros, cadastros de pessoas, empresas, projetos e demais operações são associados a uma UP específica. Essa organização evita compartilhamento indevido de dados entre unidades e permite que a plataforma opere de forma segmentada quando houver mais de uma instituição ou departamento utilizando o sistema.
