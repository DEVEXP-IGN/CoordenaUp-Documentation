# Unidades de Pesquisa (UP)

## Visualização de Detalhes

![Figura 75 - Visualização de Detalhes]({{ '/assets/media/images/unidades/unidades_show.png' | relative_url }})

<p class="caption">Figura 75 - Visualização de Detalhes</p>

A visualização apresenta os dados salvos em modo de leitura, permitindo conferência sem edição imediata.

- **Informações Exibidas:**
  - **Nome:** Nome completo cadastrado.
  - **Abreviação:** Sigla cadastrada para a unidade.

- **Ações de Visualização:**
  - **Botão Editar:** Abre o formulário de edição para correções.
  - **Botão Voltar:** Retorna à tela de listagem.
