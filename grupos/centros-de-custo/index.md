# Centros de Custo

O módulo de Centros de Custo no CoordenaUP é a unidade fundamental de controle financeiro. No sistema, a relação entre Projeto e Centro de Custo é de exclusividade (1:1): cada projeto possui exatamente um centro de custo correspondente, e cada centro de custo está vinculado a apenas um projeto. Esta amarra garante que a execução orçamentária seja isolada e auditável por iniciativa.
