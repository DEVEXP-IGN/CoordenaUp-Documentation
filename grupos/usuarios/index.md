# Usuários

O módulo de Usuários gerencia o acesso à plataforma CoordenaUP. Ele é responsável por vincular indivíduos cadastrados a credenciais de login e definir seus níveis de permissão através de uma hierarquia de funções. No CoordenaUP, o acesso é baseado em telas: se um usuário possui acesso a uma tela, ele detém permissão total para as operações contidas nela.
