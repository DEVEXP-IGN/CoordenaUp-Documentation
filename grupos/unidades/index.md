# Unidades de Pesquisa (UP)

O cadastro de Unidades de Pesquisa é a configuração mestre do CoordenaUP. Ele define as instituições ou departamentos que utilizam o sistema para gerir seus projetos. Dados financeiros, pessoas, parcerias e operações são vinculados a uma UP, permitindo uso multi-unidade ou centralizado.
