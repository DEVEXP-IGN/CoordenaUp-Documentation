# Tipos de Empresa

## Listagem de Tipos de Empresa

![Figura 62 - Listagem de Tipos de Empresa]({{ '/assets/media/images/tipos_de_empresa/tipos_de_empresa_index.png' | relative_url }})

<p class="caption">Figura 62 - Listagem de Tipos de Empresa</p>

A tela principal apresenta uma visualização organizada por grupos. Os tipos de empresa são exibidos com uma numeração de posição, facilitando a ordenação visual e a usabilidade do sistema.

### Estrutura de Exibição

- Os itens são agrupados por tipos raízes (ex: Parceira, Cliente, Prestador de Serviço). 
- Abaixo de cada raiz, são listados os subtipos (ex: Startup, Universidade, Governo).

### Ícones de Ação

- **Arrastar e Soltar (::):** Permite a reordenação manual dos itens dentro de seus grupos.
- **Lixeira (Azul):** Localizada à direita de cada item, permite iniciar o processo de exclusão do tipo de empresa.
- **Botão Adicionar (+):** Localizado no cabeçalho de cada grupo para adicionar um novo subtipo diretamente vinculado àquela raiz.

### Navegação

- **Botão Voltar:** Localizado no rodapé para retornar ao menu anterior.

Esta visualização hierárquica permite uma compreensão rápida das categorias disponíveis e facilita a manutenção da estrutura classificatória.
