# Tipos de Anexo

## Listagem de Tipos de Anexo

![Figura 68 - Listagem de Tipos de Anexo]({{ '/assets/media/images/tipos_de_anexo/tipos_de_anexo_index.png' | relative_url }})

<p class="caption">Figura 68 - Listagem de Tipos de Anexo</p>

A listagem apresenta as categorias de documentos disponíveis para uso nos uploads dos módulos do sistema.

- **Campos de Visualização:**
  - **Numeração:** Indica a posição de ordenação do tipo de anexo.
  - **Nome:** Identifica a categoria documental, como nota fiscal, termo de referência ou comprovante de pagamento.

- **Ícones de Ação:**
  - **Lixeira (Azul):** Inicia a exclusão do tipo de anexo. Antes de remover o registro, o sistema valida se existem vínculos ativos.

- **Botões de Navegação:**
  - **Adicionar (+):** Cria uma nova categoria de anexo.
  - **Voltar:** Retorna ao menu principal de configurações.
