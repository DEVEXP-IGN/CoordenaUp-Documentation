# Tipos de Pessoa

## Cadastro e Edição de Tipo de Pessoa

![Figura 66 - Cadastro e Edição de Tipo de Pessoa]({{ '/assets/media/images/tipos_de_pessoa/tipos_de_pessoa_edit.png' | relative_url }})

<p class="caption">Figura 66 - Cadastro e Edição de Tipo de Pessoa</p>

Nesta interface, o usuário define as regras de negócio e a posição hierárquica de cada perfil de pessoa.

### Campos do Formulário

- **\*Nome:** Campo de texto obrigatório para nomear a categoria (ex: "Quadro Técnico").
- **\*Posição:** Campo numérico obrigatório para determinar a ordem de listagem.
- **Descrição:** Espaço para detalhar quais perfis profissionais ou acadêmicos se enquadram neste tipo.
- **Seletor Subtipo (Alternador/Toggle):** Quando ativado, permite que este registro seja aninhado sob uma categoria raiz (pai).
- **\*Tipo Pessoa Raiz:** Dropdown obrigatório caso a opção "Subtipo" esteja ativa. Define a qual grupo principal este registro pertence.

### Ações

- **Botão Cancelar:** Descarta as alterações e retorna à tela anterior.
- **Botão Salvar:** Registra os dados de forma definitiva.

Este formulário permite criar uma estrutura de classificação flexível que se adapta às necessidades da Unidade de Pesquisa.
