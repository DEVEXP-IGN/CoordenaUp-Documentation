# Categorias Financeiras

## Cadastro e Edição de Categoria Financeira

![Figura 71 - Cadastro e Edição de Categoria Financeira]({{ '/assets/media/images/categorias_financeiras/categorias_financeiras_edit.png' | relative_url }})

<p class="caption">Figura 71 - Cadastro e Edição de Categoria Financeira</p>

Esta interface define as propriedades de uma rubrica financeira usada para classificar movimentações.

- **Campos do Formulário:**
  - **\*Nome:** Campo obrigatório para identificar a categoria.
  - **\*Posição:** Campo obrigatório que define a ordem em relatórios e listas de seleção.
  - **\*Tipo:** Campo de seleção que indica se a categoria é de entrada ou saída de recurso.
  - **Descrição:** Campo livre para detalhar o que deve ser lançado sob a rubrica.
  - **Seletor Subcategoria (Alternador/Toggle):** Define se o registro depende de uma categoria pai.
  - **\*Categoria Financeira Raiz:** Dropdown habilitado quando "Subcategoria" está marcada, permitindo o aninhamento orçamentário.

- **Ações:**
  - **Botão Cancelar:** Descarta a edição.
  - **Botão Salvar:** Grava as definições no sistema.
